# 将确定性执行与模型推理分层

AutoProgress 将可由显式规则判定的前提条件、账本状态以及源码控制与审查托管的机械协议归入确定性执行层，由代码返回有界结构化结果；模型推理层消费结果并负责人机交互、代码设计、实现与审查。模型只调用 `prepare-run`、`finish-run` 和 `recover-run` 等粗粒度入口，确定性阶段、检查点、有限重试与外部对账留在入口内部；交付时模型只声明语义，代码计算 diff、验证与版本事实并通过受信任模板合成 review 文档。失败是硬门槛，模型不得放行；失败阶段恢复自身承诺前的可逆变化但不撤销已完成阶段，不可逆副作用通过查询事实恢复。把所有步骤交给模型会重复读取状态并产生不一致判断，逐命令包装又不会降低编排成本；粗粒度分层需要维护状态、适配器和模板契约，却能节省 Token 并让安全门槛可测试、可复现。
