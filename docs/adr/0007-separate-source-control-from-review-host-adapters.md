# 分离源码控制与审查托管适配器

AutoProgress 通过独立的源码控制路由和审查托管路由组织工具集成，当前只实现 Git 与 GitHub；新项目显式配置两条路由，旧 schema v2 项目确定性采用相同默认值，禁止自动猜测或静默回退。核心只依赖工具无关生命周期能力和通用句柄，专有事实留在适配器内部，所有实现都必须声明能力并在领取额度前满足任务契约；实现只能由受信任插件注册，项目配置只选择稳定 ID，不能注入命令或仓库脚本。检查点绑定适配器及状态 schema 版本，跨版本恢复必须由明确兼容实现或保留原证据的确定性迁移完成。组合适配器会重复安全逻辑，Git 核心术语会迫使其他工具伪造概念，动态命令入口会扩大代码执行面，而无约束升级会破坏恢复；封闭注册、分离、能力可判定且状态可迁移的路由增加协调成本，却允许未来安全演进。
